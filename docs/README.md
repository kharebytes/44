# ShelfSense — Library Management Website

Frontend-only library management demo using HTML, CSS, vanilla JavaScript and LocalStorage.

## Run
1. Extract this ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. No package installation or backend is needed.

## Features
- Dashboard, catalogue, member management
- Add/edit/delete/search books and members
- Issue and return books with due dates
- Section, rack and shelf location tracking
- Activity history and CSV export
- Export all app data as JSON backup
- Responsive desktop/mobile layout
- Data persists in the same browser through LocalStorage

## Important limitation
LocalStorage is device/browser-specific and is not a shared database. This is ideal for a college demo, not a multi-user production system. Export backups regularly.
